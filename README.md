# Apple Trivia

一个轻松的中文 Apple 冷知识小游戏。点「随机来 5 题」直接开玩，猜完领个趣味称号，生成战绩图片，邀请朋友「不服来战」。

[来猜 5 题](https://yunnre060214-sudo.github.io/Apple-Trivia/?v=3.4.3) · [反馈题目](https://github.com/yunnre060214-sudo/Apple-Trivia/issues)

当前版本 **3.4.3**，题库 **4,585 道**，资料整理日期 **2026-10-18**。

仓库地址：[Apple-Trivia](https://github.com/yunnre060214-sudo/Apple-Trivia)；网站地址：[Apple Trivia](https://yunnre060214-sudo.github.io/Apple-Trivia/)。仓库更名后，原 GitHub Pages 路径 `Apple-Product-Knowledge-Quiz` 已失效。线上发布版本可通过网站的 `version.json` 核查。

## v3.4.3 主题切换性能修复

主题扩散改为单份活态备用页面与交替明暗的复合圆形裁剪。备用页面在空闲时准备，整轮连点始终共用；每次点击仅增加一个圆形裁剪轮廓，原页面的配色与浏览器底色在最后一轮完成后统一提交。按钮图标和目标状态立即反馈，支持 3、5、20 次连续触发，不等待上一轮结束。

原页面的流光、产品浮动和入场动画保持运行，备用页面同步其 DocumentTimeline、开始时间和暂停状态，不读取计算后的变换来冻结姿态，也不重新插入首页。背景光带从逐帧修改 SVG 描边改成整层变换。所有圆形轮廓共用一条 requestAnimationFrame 循环，每帧只提交一次 even-odd clip-path，不生成额外 DOM 或 SVG 遮罩资源。完成遮罩合并为一块底板，及时回收旧圆；导航、视口变化、后台与减少动态效果保留清理路径。

## v3.4.0 修复与代码优化

本版本集中修复缺陷与整理运行逻辑，题库保持 4,585 道。

- 损坏存档中的空题目记录、异常答案结构和过大题单会安全失效；继续兼容 v3.3.1 等既有有效进度，练习与快速模式清除异常限时。
- 新开普通短局清除画廊题目的旧网址；“跳至主要内容”保持当前答题页面，画廊链接恢复修饰键与新标签页语义。答题快捷键避开浏览器组合键、输入框和原生控件的 Enter。
- 主题扩散保留任意连续点击；完成的动画及时释放，键盘切题、页面隐藏、减少动态效果或外观偏好变化时清理旧副本。装饰动画观察器跳过主题副本及已移除的节点。
- 触摸滑出画廊后在文档级接收松手与取消事件，切后台后清除遗留触摸状态；启用减少动态效果时立即复位产品姿态。
- 分享预览按本局缓存生成任务，关闭或替换面板后旧回调失效并回收图片地址；生成失败可重试，旧任务失败不会覆盖新预览。
- 快速开局跳过无用的平衡抽样；隐藏的快速模式时钟停止每秒轮询，清理重复的庆祝定时器和未使用状态。网址与快捷键规则独立到 `assets/navigation.mjs`。
- 构建校验实际发布文件的引用与版本；部署检查比对预期版本，避免旧页面和旧资源返回 200 时被误判为本次发布成功。

## 界面

视觉方向为 Apple 产品档案：暖白与石墨色打底，以大字号、细分隔线和原创矢量产品展陈构成首页。六色用于品牌轮廓、渐变大标题和进度。主入口为黑白按钮，自定义保留次级权重，三个分类通过连续横排呈现。

首页展陈九款经典产品：Macintosh（1984）、iMac G3（1998）、第四代 iPod（2004）、初代 iPhone（2007）、MacBook Air（2008）、初代 iPad（2010）、Apple Watch（2015）、AirPods（2016）和 Vision Pro（2024）。日期按具体事件区分发布与首批市场开售。产品每 5 秒自动轮播，也可横向滑动切换栏，或使用前后按钮、方向键及 Home/End 键浏览。切换仅滚动产品栏，保持页面纵向位置。桌面精细指针触发小幅、带阻尼的透视响应，手指操作与减少动态效果设置保持稳定。切换按钮提供原生键盘焦点、按下状态和产品播报，离开首页即清理交互监听与待执行帧。

答题页采用开放布局，题目、选项、反馈与自动切题各自占据稳定区域。切题过渡为 220ms，方向与上一题／下一题对应；短距离滚动保留，深入解析后的切题仅回到新题干。自动切题的 1.65 秒等待以细线倒计时反馈，查看解析、切后台或取消定时会同时停止提示。答案使用底色、描边、符号和文字描述共同表达状态。

结算与 1080 × 1440 分享图共用档案单页构图：大分数、清晰的称号和两行统计。短局结算展示逐题对错。手机上的自定义、关于与分享使用底部面板，明确重置浏览器原生弹窗的最大宽度，确保左右边缘对齐；按钮保留 44px 以上触控高度，输入字体保留 16px。深色单独配置背景、文字、状态与分隔线。

每次进入播放 hello，可点右下角 skip 或按 Escape 跳过。进入首页后，标题、产品和背景光带依次展开。大标题改用本地托管的 Outfit 字体，彩色直接融入文字，移除 Apple 下方的装饰短条；中英文两行使用实际字形边界测量做光学对齐。

明暗切换共用一份预备的活态备用页面，复合圆形裁剪按点击顺序交替显示和擦除另一套配色，支持多次快速连点。备用页面与原页面同步动画时钟，SVG 绘图 ID 使用独立命名空间，不可聚焦，也不拦截鼠标和触摸；滚动、缩放、其他导航操作或页面退出时清理遮罩。Safari 的页面外底色和浏览器主题色在最终扩散完成后再提交。

浅色使用纸白底、彩色折射光带与柔和投影；深色单独配置靛蓝底、星点、轨道、发光字色和产品照明。更多研究来源与取舍见 [设计研究与迭代记录](docs/design-research.md)。

全站交互采用分场景动效：品牌轻摆、开始按钮的洗牌与推进、主题图标转动、产品切换的方向响应、分类图标动作、答案判定描线、题数滑块跨行移动、领域开关回弹、原生选择器指示、解析折叠、弹窗退出，以及复制／保存／分享成功后的短暂对勾。触摸按压保持到松手，滑动或取消时回正；键盘操作复用相同反馈。动态生成的控件自动接入，链接与按钮保留原语义和点击区域，导航及原生分享调用不等待装饰动画。启用减少动态效果时停止非必要运动，保留结果反馈。详细映射与边界见 [交互动效规范](docs/interaction-motion.md)。

首页 9 张产品各自带有日期、事件简介与专属题目。点击年份或简介即可进入对应的一题练习，也支持 `#q=gallery-macbook-envelope` 这类可分享直达链接。日期区分发布与首批市场开售，题目保留资料来源。iMac G3 后壳与提手重新闭合连接。

画廊每 5 秒自动循环，手动选取后重新计时；悬停、键盘操作、触摸滑动、开场播放、弹窗、后台和离屏时暂停，支持单独暂停／继续。产品名称下方共用一根平移彩虹指示条。背景流动光带、轨道与产品浮动使用不同节奏，启用减少动态效果时停止入场、自动轮播与循环装饰。Outfit 以 SIL Open Font License 托管，许可证见 `assets/fonts/OFL.txt`。

## 玩法

每次进入、刷新或从浏览器往返缓存返回网站，均播放彩色手写 hello 开场；右下角 skip 和 Escape 可提前淡出进入，Tab 可聚焦 skip。开场代码和关键样式在构建时内联到 HTML，不依赖题库及外部模块下载；切到后台时暂停，返回前台继续。开场的 skip 按钮不依赖模块加载。在「关于」中仍可重播。

- **随手一局**：无需配置，随机 5 题。默认三道手写趣味题、一道年份题、一道既有轻松题，避开规格细节，尽量避免同一局重复相同主题。
- **分类挑战**：反直觉、产品历史、发布年份，点击就开玩。
- **选完就走**：短局选答案后显示对错，约 1.65 秒后自动切题；点「解析」可停下来读解析，也可关闭自动切题。
- **自选节奏**：保留 5 至 500 题、自选领域与难度，以及自由切题后揭晓、每题确认看解析两种完整玩法。自由切题模式可选全局限时。
- **轻松结算**：趣味称号、答对题数、分数与用时。满分、三连对和快速完成有额外文案或动画。
- **分享战绩**：预览并下载 1080 × 1440 PNG，包含分数、称号、网站地址和「不服来战」。支持时可调用系统分享，也可复制文字。
- **接着玩**：自动保存当前局的题目、选项、答案、记号、位置和截止时间。兼容旧版 1.0.0、1.0.1 的有效进度。
- **少遇熟题**：近期记录按实际浏览顺序更新，重复访问移到队尾。题池用尽时优先补入最久未见的题。

未完成的局可从首页「接着上次玩」恢复；点击新的开玩入口会直接替换当前局。进度只保存在当前浏览器，不跨设备同步。网站不包含账户系统、统计 SDK、复习计划或成长曲线。旧版错题和历史记录不再展示，已有浏览器数据保留。

## 题库构成

| 内容 | 数量 | 说明 |
| --- | ---: | --- |
| 手写趣味题 | 265 | 产品故事、历史弯路、容易猜错的功能，包括 85 道 iOS 功能沿革题与 9 道画廊考点 |
| 系统年份与时间线 | 2,419 | 19 道系统首次亮相年份题，以及 2,400 组不重复的产品／系统年份关系 |
| 原有内容及补全年份 | 1,901 | 保留原有 1,866 道题，补全旧款 iPad 等年份后增加 35 道相关题 |
| 合计 | 4,585 | 唯一题干，四个不同选项，唯一正确答案，附解析和来源 |

时间线题由有限的已记录年份组合生成，**2,400 组关系不代表 2,400 条独立史实**；每一对只出现一次，不倒置重复、不改写同一题来扩数。两者同年公布时明确采用「同年亮相」，不混同为同一天。系统采用首次预览年份，硬件采用首次公布年份，不比较各地区开售日。

短局对题型设置权重，让大规模年份关系题不会淹没手写趣味题。原有规格内容保留给自定义玩法；首页默认 5 题排除规格、参数比值和双条件选型题，同一局也尽量只抽一道 iOS 功能沿革题。

### 内容来源

绝大多数题目链接到 Apple 新闻稿、技术规格或用户指南。AirPower 取消、地图致歉两题引用保存 Apple 原始声明的媒体页面，并在界面标记「历史声明存档」。键盘服务计划题讨论当年的方案，并不意味着该方案今天仍可申请。

源码分工：

- `src/catalog.json`：逐型号事实和来源，补齐旧款 iPad 的首次发布年份。
- `src/editorial.mjs`：既有手写题、芯片和其他产品事实。
- `src/trivia.mjs`：手写趣味题、iOS 功能沿革和系统年份记录。
- `src/timeline.mjs`：按固定种子生成不重复的时间线关系题。
- `src/bank.mjs`：构建完整题库。
- `src/engine.mjs`：抽题、近期记录、恢复进度、结算和彩蛋规则。
- `assets/app.mjs`：界面与玩法，选答案时局部更新按钮和进度，切题时只替换题目区域。
- `assets/theme.mjs`、`assets/theme-scene.mjs`：明暗外观的遮罩扩散、预备页面与共享动画时钟。扩散半径包含移动端完整快照范围；页面外观与浏览器底色分别使用 `data-theme`、`data-browser-theme`，动画完成后同步底色、根配色方案和浏览器主题色。
- `assets/motion.mjs`、`assets/motion.css`：全站交互分类、按压保持与回弹、图标语义动作、表单选择、高度折叠、弹窗退出和真实操作完成后的反馈；减少动态效果及清理机制。
- `assets/hello.mjs`、`assets/hello.css`：每次进入必播的开场控制与关键样式，在构建时内联。手写路径改编自 [Chánh Đại Apple Hello Effect](https://github.com/ncdai/chanhdai.com/blob/main/src/registry/components/apple-hello-effect/apple-hello-effect-english.tsx)，MIT 许可保留于 `assets/hello-LICENSE.txt`。
- `assets/icons.mjs`、`assets/brand.mjs`：统一线性 SVG 图标与 Apple 官网咬口苹果轮廓。品牌沿用轮廓，配以六色条纹。
- `assets/gallery.mjs`、九份产品 SVG：原创经典产品展陈与手动切换、指针响应。
- `assets/navigation.mjs`：题目网址、原生链接语义与答题快捷键。
- `assets/share.mjs`：与结算页一致的本地 Canvas 分享图，以及可取消预览与任务缓存。
- `scripts/verify-release.mjs`：发布文件引用、缓存参数和题库元信息的一致性校验。

题库在构建时生成，运行时不调用 AI 或第三方题库。分数为每题等权的百分制，未猜计错。引擎保留旧版计算字段以兼容已有逻辑，界面不再展示难度加权分或复杂领域统计。

## 开发与验证

Node.js 22 或更新版本，无第三方运行依赖。

```sh
npm test
npm run build
python3 -m http.server 8080 --directory dist
```

通过 HTTP 打开 `http://localhost:8080`。主题中间帧可在 URL 添加 `motion=slow` 做慢速诊断，正常访问仍采用 780ms 扩散。构建会校验题库超过 4,000 道，并输出分类、题型与难度统计。测试覆盖题目唯一性、抽取条件、短局内容比例、连续开局去重、最近访问顺序、同年时间线、存档恢复、结算及彩蛋。

界面适配手机和桌面，提供深浅外观、键盘操作与 `prefers-reduced-motion` 支持。所有插画由 CSS／SVG 绘制，分享图在本地 Canvas 生成，无需外部图片请求。
