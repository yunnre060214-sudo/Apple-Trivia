# v4.0 验证记录

日期：2026-10-24。基线：v3.7.0 / `bedeb9e`。发布目标：v4.0.0。

## 内容

新增 100 道独立手写题与 32 道图片题，合计 4,717 道。图片题由 9 道产品辨认、15 道部件与设计题、8 道接口题构成。每题保留解析、文字描述和 Apple 资料链接；图片由 `scripts/build-visuals.mjs` 可复现生成。手写题的 100 个事实键互不重复。已识别的旧题同义关系使用显式知识点组；该映射不代表对所有旧题完成了语义审校。

新增来源按 15 组原始新闻稿核查，见 `v4-content-sources.json`。图示不是工程图或照片；接口外形不会被用来推出 USB 速率、雷雳能力等无法从形状确定的参数。

## 自动测试与浏览器

- 108 项 Node 测试通过，覆盖原有引擎与动效、100 条新事实、32 张图示、知识点去重、存储回退、1 至 500 题的挑战重建、变更题目失效及有效旧进度兼容。
- Chromium 与 WebKit 分别通过 12 组真实浏览器流程。测试环境为 Linux Playwright 1.51.1；Chromium 134，WebKit 为该版本随附引擎。包含 320、393、768、1440px 布局检查、20 次连续明暗切换、答题与解析、结算、分享图片下载、挑战链接固定顺序与刷新续答、导航中断、减少动态效果、图片失败、损坏链接、长题干、真实 v3.7.0 进度恢复、500 题导航与分享，以及存储不可用。
- 1080 × 1440 的实际导出 PNG 已用独立 jsQR 解码，二维码内容与复制的挑战链接完全一致。
- 对 32 张插图进行了总览检查，调整 MacBook Air 键盘与触控板的圈选标记。根据 [Apple 充电说明](https://support.apple.com/en-us/119912) 修正初代 AirPods 充电盒的指示灯到盒内。检查手机答题、桌面双列答题、两种首页外观与分享弹窗截图。

浏览器用例保存在 `scripts/browser-smoke.mjs`，CI 会运行 Chromium 和 WebKit，并上传截图、PNG 与 JSON 报告。运行：

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm test
npm run build
npm run test:browser
QA_BROWSER=webkit npm run test:browser
```

## 性能诊断

同一 Linux 无图形加速环境、1440 × 1000 视口，旧版与新版各运行三次。加载、字体及入场稳定后，每 35ms 点击一次主题按钮，共 20 次。

| 指标 | v3.7.0 | v4.0.0 |
| --- | --- | --- |
| 三次运行的 rAF 帧间隔 P95 | 300 / 283.4 / 266.6ms | 133.4 / 150 / 116.6ms |
| 单次点击处理耗时中位数 | 2.2 / 1.9 / 1.8ms | 2.4 / 2.1 / 2.1ms |
| 单次点击处理耗时最大值 | 5.8 / 4.4 / 5.0ms | 3.8 / 8.9 / 4.0ms |
| 运行末尾 JavaScript 堆快照 | 约 11.9MB | 约 12.7MB |
| 未完成扩散 | 0 | 0 |
| 保留的备用页面 | 0～1 | 1 |

移除大面积实时模糊后，软件绘制环境中的帧间隔明显减少；新增界面和备用页面带来约 0.8MB 堆快照差异。快照没有强制 GC，不能作为泄漏结论。这组数据仅支持相对诊断，不能宣称已达到真机 60fps 或满足现场 INP 指标。

## 发布与边界

`package.json` 和引擎版本由 `npm run version:set -- 4.0.1` 同步更新，锁文件同时更新。HTML、CSS 和模块图中的 `?v=__VERSION__` 在构建时统一写入；构建核验所有模块和资源引用，并校验题库与 `version.json` 一致。

挑战链接只存题目 ID、选项排列和内容指纹，不存答案或成绩。内容指纹用于发现意外变更，不提供防作弊或成绩认证；网站继续在本地判分。短题单分享图含二维码，长题单提供复制链接。旧版 v3.5.0、v3.6.0、v3.7.0 的有效进度已纳入兼容。

Linux WebKit 验证不等同于 iPhone Safari 真机验收，Safari 工具栏、键盘和系统安全区仍存在平台差异。本轮没有 iPhone、Mac 真机或独立 Edge 实机验证；Chromium 与 WebKit 流程通过不延伸为这些环境已通过的声明。
