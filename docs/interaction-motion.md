# Apple Trivia 交互动效规范

v3.4.2 · 2026-10-19

## 动作层次

每次交互按意图、接触、状态、完成四个层次处理。同一产品、题数或导航格子的重复控件沿用本场景动作语义，通过稳定标识区分幅度与回弹节奏。动态插入的按钮、资料链接、表单和折叠项经委托监听及 MutationObserver 自动接入。

| 场景 | 动作细节 |
| --- | --- |
| 品牌、关于、题库入口 | 品牌支点轻摆；文字下划线从中心展开；题数上提与外链角标分离响应 |
| 随机开始、再来一局、继续进度 | 洗牌图标扭转、圆盘箭头推进；结算重玩另用回转；历史图标回拨 |
| 深浅外观 | 每次点击生成轻量圆形遮罩，整轮连点共用一份持续播放的备用页面；按钮立即反馈，最终一轮完成后提交配色与浏览器底色 |
| 产品展陈 | 前后箭头定向回弹，单根六色指示条在名称下平移；每 5 秒循环，暂停键有独立按压和图标过渡，横向滚动保持纵向位置 |
| 三个分类 | 灯泡点亮式轻摆、历史回拨、时针前进；行文字和末尾箭头分层运动 |
| 返回、前后题、确认、结束 | 返回向左收；下一题向右伸；确认收紧回弹；结束箭头提起转向 |
| 答案 | 触摸接触压缩，字母徽标回弹；正确描出对勾，错误轻微横向修正；其他答案降低视觉权重 |
| 解析、自动切题 | 解析箭头转向与正文、来源分层出现；自动开关滑块伸缩和回弹，保留原倒计时 |
| 题数、领域、输入 | 题数背景使用位置与比例反向变换平滑跨行；领域独立回弹；数字、只读文字框通过边线和底色反馈焦点 |
| 难度、玩法、限时 | 保留原生 select，装饰箭头响应打开、选择、Escape 与失焦；焦点边线延展 |
| 题目地图、标记 | 四宫格分拍压缩；题号格子独立回弹；标记旗摆动并保留选中状态 |
| 结算与分享 | 结算操作分层进入；分享图显影；下载向下、分享向上、复制错层；实际成功后暂显对勾 |
| 全部资料与仓库链接 | 资料线从右侧伸展，仓库从中心展开，页脚外链朝右上角响应 |
| 解析列表与弹窗 | 折叠高度可中途反向；折叠结束恢复固有高度；弹窗关闭短暂下移，保留原生 Escape、焦点恢复 |

## 时序与输入

- 接触压缩约 90ms，按住后保持，松开才回弹；触摸移动超过 10px 或 pointercancel 时以 160ms 回正，无额外弹跳。
- 大多数回弹约 260–420ms，图标意图动作约 420–680ms，交互触发动效均有限次运行；首页的低幅循环单独配置。
- 导航、提交、复制和系统分享立即执行；装饰动作不延迟业务。显式关闭弹窗保留 150–190ms 退出，减少动态效果或无动画 API 时立即关闭。
- 前后题仍保留原滚动上下文。产品栏只进行自身横向滚动。动画不挤动按钮布局；按压时捕获指针，防止视觉缩小时丢失边缘点击，滑动或取消时解除捕获。
- 悬停动作仅用于精细指针。触摸、键盘及减少动态效果各有独立路径；减少动态效果保留静态成功对勾、文字和原有焦点轮廓。

## 中断与清理

重复触发会替换同一元素同一通道的动画；读取当前状态后继续回弹。页面节点移除时取消相关动作；切后台、离开页面或动态启用减少动态效果时清理动作和短暂成功状态。浏览器往返缓存恢复后，委托监听保持可用。

折叠项可在展开和收起之间反向。弹窗关闭中重新打开会取消旧退出，避免迟到回调关闭新弹窗。复制与分享被拒绝或取消时不显示成功对勾。原生选择菜单和系统分享界面由浏览器及操作系统绘制，网站只控制页面内的指示与反馈。

## 验证

`npm test` 包含动作分类、按压保持、松手回弹、触摸滚动取消、禁用与 inert、题数滑块、原生选择器、弹窗退出中断、折叠反向、成功反馈及减少动态效果的回归。发布检查同时覆盖既有题库、hello、主题扩散与进度恢复。

DOM 模拟覆盖首页、关于、快速答题、反馈及资料链接、继续进度、结算、分享、复制回退、自定义配置、练习确认、题目地图和结束确认等 13 个状态，逐一断言控件已匹配语义动作。抽题产生的资料链接数量会变化。DOM 模拟不验证浏览器布局、绘制或真实设备帧率；当前受托管预览环境限制，浏览器逐帧视觉效果未验证。

## 首页循环与开场

产品轻浮动、标题和页脚色带流动、开始箭头及分类图标以不同周期自动循环。减少动态效果时关闭这些循环及自动轮播。画廊悬停、键盘焦点、触摸操作、后台、离屏、开场及弹窗分别管理暂停状态，离开首页时清理计时器与观察器。hello 每次访问重播，可用 skip 或 Escape 提前淡出；开场尚未开始绘制时也可跳过，之后仍可重播。

## 画廊考点与首页入场

年份和事件简介均为带有真实题目地址的链接。图片、日期、故事和题目 ID 共享一份数据源，直接链接打开单题练习。标题采用 Outfit 与中文系统字体组合，根据 Canvas TextMetrics 的字形可见边界校正两行左缘。hello 结束后，文字分层揭示，产品从较小比例与明显位移进入，背景光束扫过；离开后再返回首页会重新入场。

浅色呈现纸白、折射彩带与柔和投影；深色以靛蓝、星点、轨道及独立的字色和产品光影组成。所有循环和入场均尊重减少动态效果设置。

## 主题合成与动画连续性

备用页面在空闲时准备，首个输入到来时同步原页面的 CSSAnimation 开始时间、播放速率与暂停状态；同一轮中的后续点击仅新增 SVG 遮罩圆，采用亮度遮罩交替显示／擦除另一套配色。扩散为 780ms，完成的旧圆合并成底板，后来发出的圆保持运行。原页面不重建，不修改已有循环的时间，不在每次点击中重新读取计算样式、克隆整页或冻结变换。尚未完成准备时，按钮先响应，多个输入共用下一帧的准备工作。

SVG 背景光带改为整层 transform 动画，减少持续修改 stroke-dashoffset 的重绘。自动测试验证单份备用页面、20 次连点、冷启动队列、遮罩顺序、时间轴同步、唯一 SVG ID 与中断清理；真实设备帧率仍需分别在设备上验证。

遮罩直接动画 SVG 圆的几何半径，使用完整视口作为资源画布。开发检查可添加 `motion=slow` 参数观察 6 秒扩散的中间态；默认时长仍为 780ms。
